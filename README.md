# webbapp_tg


# 📊 Финансовый Ассистент Telegram Web App

Интерактивное мини-приложение (Mini App) для Telegram, разработанное для управления личными финансами, расчета инвестиций и планирования выплат по долгам.

---

## 🛠 Функционал приложения

1. **📈 Калькулятор сложного процента** — расчет итогового капитала с учетом ежемесячных пополнений и капитализации процентов.
2. **📉 Стратегия «Снежный ком» (Debt Snowball)** — пошаговый план ускоренного закрытия нескольких кредитов от меньшего к большему с учетом финансового «ускорителя».
3. **💰 Расчет финансовой подушки** — быстрый калькулятор резервного фонда безопасности на 3, 6 или 12 месяцев.

---

## 💻 Стек технологий

* **Frontend:** HTML5, CSS3 (с поддержкой нативных тем Telegram), JavaScript (ES6)
* **Backend:** Python 3.x, библиотека `pyTelegramBotAPI` (или `telebot`)
* **Интеграция:** Telegram WebApp API
* **Хостинг:** GitHub Pages

---

## 🔧 Как запустить проект локально

### 1. Клонируйте репозиторий:
```bash
[git clone https://github.com](https://github.com/vladdavydov1999)
cd webapp_tg
```

### 2. Настройте Python-бота:
1. Установите зависимости:
   ```bash
   pip install pyTelegramBotAPI
   ```
2. Откройте файл `main.py` и вставьте ваш токен от `@BotFather` в переменную `TOKEN`.
3. Запустите бота:
   ```bash
   python main.py
   ```

### 3. Подключение Web App в Telegram:
Через `@BotFather` задайте URL кнопки меню вашего бота, указав ссылку на ваши GitHub Pages.
